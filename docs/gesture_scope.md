# Gesture meaning and scope

The camera's common-pose detector identifies hand geometry. Some everyday uses provide a tentative message suggestion, but gestures are contextual and are not equivalent to a verified Indian Sign Language (ISL) translation. The visitor must confirm any suggested meaning before it is added to the conversation.

| Detected pose | Suggested everyday message | App treatment |
|---|---|---|
| Thumbs-up | “I’m okay” / “मैं ठीक हूँ” | Informal approval cue; visitor confirmation required. |
| Thumbs-down | “I don’t think this is okay” / “मुझे यह ठीक नहीं लगता” | Informal disapproval cue; it does not claim the visitor is medically unwell. Confirmation required. |
| OK handshape | No sentence inference | Shape label only; meanings vary by context and culture. |
| Closed fist | No sentence inference | Shape label only. |
| Shaka | No sentence inference | Shape label only; meanings vary by context and culture. |

ISLRTC describes its Indian Sign Language Dictionary as videos of signs with Hindi/English translation equivalents. A culturally familiar hand pose should therefore not be called an ISL sign unless it has been checked against the dictionary and reviewed by a Deaf signer or qualified ISL interpreter.
